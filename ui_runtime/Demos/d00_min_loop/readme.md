时间线 + 数据流
```
Time →
 ┌─────────────────────────────────────────────────────────┐
 |                  OS 消息队列                           |
 |  [CreateWindow] → [Expose] → [MouseMove] → [Quit] ...   |
 └─────────────────────────────────────────────────────────┘
         │
         │  (需要 PollEvents 抽出来)
         ▼
 ┌───────────────────────────┐
 |   GLFW 程序事件循环         |
 |   while(...) {            |
 |      glfwPollEvents();    |   ← 通道 A: 系统消息 → 程序
 |      渲染命令();           |
 |      glfwSwapBuffers();   |   ← 通道 B: 程序缓冲 → 屏幕
 |   }                       |
 └───────────────────────────┘
         │
         ▼
 ┌───────────────────────────┐
 |      窗口系统 + 显示器      |
 |  [外壳显示] + [画面更新]    |
 └───────────────────────────┘
```
